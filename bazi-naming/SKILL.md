### 一、四柱八字基础

**四柱** = 年柱 + 月柱 + 日柱 + 时柱
**八字** = 四柱的天干地支 = 8个字

每个柱 = 1个天干 + 1个地支

**十天干**：甲、乙、丙、丁、戊、己、庚、辛、壬、癸
**十二地支**：子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥

### 三、五行相生相克

**相生**（顺序循环）：木→火→土→金→水→木
- 木生火：木燃烧产生火
- 火生土：火烧后成灰土
- 土生金：土中蕴藏金属矿物
- 金生水：金属熔化后像水，或金属表面凝结露水
- 水生木：水滋养树木生长

**相克**（隔一位）：木→土→水→火→金→木
- 木克土：树根扎入土壤
- 土克水：土能阻挡水流
- 水克火：水能灭火
- 火克金：火能熔化金属
- 金克木：金属工具能砍伐树木

### 四、八字排盘方法

#### 年柱计算
```
年干 = (年份 - 3) % 10 → 对应天干序号（1=甲, 2=乙, ..., 10=癸）
年支 = (年份 - 3) % 12 → 对应地支序号（1=子, 2=丑, ..., 12=亥）
注意：立春为新年起点（约2月4日），立春前算上一年
```

#### 月柱计算（年上起月法）
根据年干确定正月天干：
- 甲己年 → 正月丙寅
- 乙庚年 → 正月戊寅
- 丙辛年 → 正月庚寅
- 丁壬年 → 正月壬寅
- 戊癸年 → 正月甲寅

然后顺推：二月、三月...

**月份与地支对应**（按节气）：
- 正月（寅月）：立春~惊蛰
- 二月（卯月）：惊蛰~清明
- 三月（辰月）：清明~立夏
- 四月（巳月）：立夏~芒种
- 五月（午月）：芒种~小暑
- 六月（未月）：小暑~立秋
- 七月（申月）：立秋~白露
- 八月（酉月）：白露~寒露
- 九月（戌月）：寒露~立冬
- 十月（亥月）：立冬~大雪
- 十一月（子月）：大雪~小寒
- 十二月（丑月）：小寒~立春

#### 日柱计算
使用已知基准日推算。基准：1900年1月31日 = 甲辰日。
或使用万年历查询（推荐，因为日柱计算复杂）。

#### 时柱计算（日上起时法）
根据日干确定子时天干：
- 甲己日 → 子时甲子
- 乙庚日 → 子时丙子
- 丙辛日 → 子时戊子
- 丁壬日 → 子时庚子
- 戊癸日 → 子时壬子

**时辰与地支对应**：

- 丑时：01:00-03:00
- 寅时：03:00-05:00

- 巳时：09:00-11:00

### 五、五行强弱与日主分析

**日主（日元）**：日柱的天干，代表命主本人。

**判断日主强弱**：
1. **看月令**：日主生在哪个季节（月支）
   - 木日主：春（寅卯）旺，冬（子亥）相，秋（申酉）死，夏（巳午）休，四季（辰戌丑未）囚
   - 火日主：夏（巳午）旺，春（寅卯）相，冬（子亥）死，秋（申酉）囚，四季（辰戌丑未）休
   - 土日主：四季（辰戌丑未）旺，夏（巳午）相，春（寅卯）死，冬（子亥）囚，秋（申酉）休
   - 金日主：秋（申酉）旺，四季（辰戌丑未）相，夏（巳午）死，春（寅卯）囚，冬（子亥）休
   - 水日主：冬（子亥）旺，秋（申酉）相，春（寅卯）死，夏（巳午）囚，四季（辰戌丑未）休

2. **看同类**：八字中与日主五行相同的字数（比肩、劫财）
3. **看生助**：八字中生助日主的字数（印星）
4. **看克泄**：八字中克制、消耗日主的字数（官杀、食伤、财星）

**日主强弱判定**：
- **身强**：同类+生助 ≥ 4个，或得月令且同类≥3
- **身弱**：同类+生助 ≤ 2个，或失月令且同类≤2
- **中和**：同类+生助 = 3个

### 六、喜用神判定（核心！）

**喜用神**：八字中对日主起帮扶平衡作用的五行。

**基本原则**：
- **身强**：喜克泄耗（官杀、食伤、财星）
- **身弱**：喜生扶（印星、比劫）

### 九、起名综合分析流程

1. **排四柱**：根据出生年月日时，排出年柱、月柱、日柱、时柱
2. **定日主**：日柱天干即命主
3. **看五行**：统计八字中金木水火土各出现几次
4. **判强弱**：根据月令、同类、生助、克泄判断日主强弱
5. **取喜用**：根据强弱取帮扶平衡的五行
6. **调寒暖**：冬生需火调候，夏生需水调候
7. **看生肖**：根据属相选择宜用字、避开忌用字
8. **选汉字**：在喜用五行中选字，兼顾生肖宜忌
9. **配姓氏**：结合姓氏，检查音律、谐音、笔画

## 注意事项

1. **八字排盘以立春为界**：春节前后的年份判断以立春（约2月4日）为准
2. **时辰以当地时间为准**：建议用真太阳时校准
3. **喜用神是核心**：不要只看缺什么补什么，要看喜什么补什么
4. **生肖宜忌是辅助**：优先满足五行喜用，再考虑生肖宜忌
5. **不迷信**：八字起名是传统文化参考，不是决定因素
6. **多方案对比**：至少提供3-5个不同组合方案
7. **字义优先**：即使五行合适，也要选寓意好、音律优美的字
