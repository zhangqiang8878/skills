# 中文起名助手 — Chinese Naming

## 触发条件

当用户要求：
- "帮我起个名字"
- "给宝宝取名"
- "起名字"
- "取名参考"
- "起个有文化底蕴的名字"

## 核心原则

### 五法六忌（《左传·桓公六年》）

**取名五法**：
1. **信**：以人与生俱来的标记（如胎记、出生时辰特征）
2. **义**：以美德期望命名
3. **象**：以形貌相似之物命名（如孔子名"丘"，因头顶凹陷）
4. **假**：假托万物之名（如孔子得鲁昭公送鲤鱼，取名"鲤"）
5. **类**：与父亲相关的名字

**取名六忌**：
- 不以国、不以官、不以山川、不以隐疾、不以畜牲、不以器币

### 名、字、号关系

| 类型 | 用途 | 特点 |
|------|------|------|
| **名** | 长辈/君王称呼 | 出生后取，跟随一生 |
| **字** | 平辈/晚辈称呼 | 冠礼时取，与名相关（并列/辅助/矛盾/补充/引申） |
| **号** | 自称/文人互称 | 自由选取，寄托情怀品格 |

### 起名建议原则

1. **优先先秦典籍**：《诗经》《楚辞》《尚书》《论语》《周易》等，文字古朴大气
2. **避免过于柔美**：女孩名以端庄优雅为主，男孩名以阳刚中正为主
3. **注意谐音**：连姓检查，避免产生不良联想
4. **声调搭配**：平仄相间，朗朗上口
5. **字形美观**：避免过于生僻，但不宜太常见

## 交互式引导流程

**严格按照以下步骤与用户交互，不要跳过：**

### 第一步：基础信息收集

使用 `clarify` 工具依次询问：

1. **姓氏**（开放式问题）
2. **性别**：男孩 / 女孩 / 中性
3. **出生信息**（可选）：年份/时辰（用于五行参考）
4. **名字长度**：单字名 / 双字名 / 都可以

### 第二步：风格偏好

使用 `clarify` 提供选择：
- **古典庄重**：来自《尚书》《论语》，古朴大气
- **诗意唯美**：来自《诗经》《楚辞》，意境优美
- **儒雅君子**：来自儒家经典，品德寓意
- **豪迈壮阔**：来自《楚辞》《周易》，气势宏大
- **清新自然**：来自诗词自然意象，灵动活泼
- **都可以，由你推荐**

可以多选。

### 第三步：期望寓意

使用 `clarify` 提供选择：
- **品德修养**：谦逊、诚信、仁爱、正直
- **才华智慧**：聪慧、学识、文采、敏锐
- **健康平安**：安康、长寿、强壮、无恙
- **事业成就**：成功、建功、立业、远大
- **气质风骨**：清高、坚韧、洒脱、超然
- **家庭和睦**：孝顺、友爱、温馨、传承

可以多选。

### 第四步：禁忌和限制

使用开放式 `clarify` 询问：
- 是否有需要避开的字（如家族避讳）
- 是否有特别喜欢的字希望包含
- 其他特殊要求

### 第五步：生成候选名字

根据收集的信息，从名字数据库中筛选匹配的名字。

**每个候选名字必须包含**：
1. **全名**（姓+名）
2. **出处**：具体到哪部典籍的哪一篇
3. **原文**：引用原句
4. **寓意**：名字的深层含义
5. **音律**：拼音+声调分析
6. **适用性**：为什么适合这个孩子

**输出格式**：

```
## 📝 候选名字（共X个）

### 1. [姓][名]
- **出处**：《典籍名·篇名》
- **原文**：「引用原句」
- **寓意**：详细解释
- **音律**：拼音（声调分析，如"平仄平，朗朗上口"）
- **适合理由**：结合用户需求说明

### 2. [姓][名]
...
```

### 第六步：用户反馈与调整

询问用户：
- 是否有喜欢的名字
- 是否需要更多选项
- 是否需要对某个名字深入分析
- 是否需要调整方向重新生成

## 注意事项

1. **不要凭空编造名字**：所有名字必须有典籍出处
2. **出处必须准确**：标注具体到哪部典籍的哪一篇
3. **考虑现代语义**：古代好名字在现代可能有歧义，需要检查
4. **姓氏搭配**：生成名字时必须结合用户提供的姓氏，检查连读效果
5. **避免生僻字**：优先选择常用字，除非用户特别要求
6. **女孩名优先端庄**：避免过于柔媚、花哨的字
7. **男孩名优先中正**：避免过于阴柔或霸气的字
